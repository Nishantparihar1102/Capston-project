# Capston-project - VoiceOps 2026: ZentroMart AI Customer Support Agent

An enterprise-grade, grounded voice and conversational support assistant built for **ZentroMart**, developed for the **VoiceOps 2026 Capstone Project** (*"From Tokens to Transformers: A Course on GenAI x LLM Mastery"* by Consulting & Analytics Club, IIT Guwahati × Gnani.ai).

---

## 📁 Repository Structure

- **`team_name_voiceops/`**: Main system implementation, multi-turn agent logic, RAG engine, Gnani STT/TTS voice pipeline, evaluation scripts, and PDF report.
- **`Capstone_Project_Dataset_FTTT_2026/`**: Knowledge base policies (`kb/`), product catalog (`products.csv`), pincode serviceability (`pincodes.csv`), and benchmark questions.
- **`test_audio/`**: Customer query audio recordings for speech recognition and end-to-end voice pipeline testing.
- **`sample_outputs/`**: System output logs, evaluation comparisons, and benchmark results.
- **`6ad64c83eae85_voiceops_2026_capstone_brief.pdf`**: Official problem statement and evaluation rubric.
